# The Oasis Customer

The Oasis Customer is a customer-facing booking website where guests can browse cabins, make reservations, and manage their profiles using a shared API and database.

## Features

### Authentication

- Sign up and log in using Google Authentication
- Secure OAuth-based login flowm
- Authentication required to reserve cabins or manage reservations
- Automatic creation of a guest profile in the database upon first Google sign-in

### Cabin

- Public access to information about the Wild Oasis Hotel
- View detailed information for each cabin
- See booked and unavailable dates for cabins
- Filter cabins by maximum guest capacity

### Reservation

- Reserve cabins for a selected date range
- Reservations are created with an “unconfirmed” status
- Payments are made at the property upon arrival (no online payments)
- View all past and upcoming reservations
- Update or cancel existing reservations

### Guest Profile Management

- View and update basic guest profile information

### User interface & Experience

- Mobile-optimized UI for quick browsing and reservation management
